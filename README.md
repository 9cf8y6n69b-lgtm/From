<p align="center"><b>Forums Bot</b> — بوت ديسكورد لإدارة المنتديات والتجمعات مع داشبورد تحكم كامل.<br>
Discord bot for managing forums (communities) and gatherings, with a web dashboard.</p>

## المميزات

- **تقديم المنتدى:** نموذج (الاسم، العدد، يوزر التيك توك) يوصل للإدارة بزر قبول/رفض.
- **قواعد تلقائية:** حد أدنى لأعضاء المنتدى، منع تكرار الأسماء، منتدى واحد فقط للشخص، وانتظار بعد الخروج (3 أيام افتراضياً).
- **عند القبول:** رتبة باسم المنتدى، 4 رومات صوتية، 3 رومات شات، وروم خاص بالأونر عليه لوحة تحكم بصورة.
- **لوحة الأونر:** دعوة، إخراج، باند، فك باند، تحذير، فعالية، لوق، نائب، تغيير الاسم.
- **النواب:** الأونر يعيّن نواب بصلاحيات محدودة.
- **التحذيرات:** عدد معين من التحذيرات يطلّع العضو تلقائياً.
- **التجمعات:** لوحة "تجمع / انتهى تجمع" يمنشن رتبة منتدى المسؤول (أو رتبة التجمع إذا ما كان بمنتدى)، ويرسل إشعار في روم صور التجمعات.
- **تصميم عربي كامل:** كل رسالة إمبيد لها صورة عربية، وإيموجيات خاصة بالبوت بنفس تصميم اللوقو (تُرفع تلقائياً كـ Application Emojis).
- **الداشبورد:** تعديل كل الإعدادات والحدود، وإدارة المنتديات والأعضاء، نقل الملكية، السجلات.
- **النسخ الاحتياطي:** `/backup` و`/restore`، ورفع خط مخصص بـ `/set_font`.

## التشغيل

```bash
pip install -r requirements.txt
cp .env.example .env     # عبّي التوكن و GUILD_ID وكلمة سر الداشبورد
python bot.py
```

الداشبورد: `http://IP:8080` — وفعّل **Server Members Intent** من بوابة المطورين، وأعطِ البوت صلاحية Administrator.

## الإعداد الأولي في ديسكورد

1. `/setup` لتحديد روم الطلبات وروم الإشعارات وروم الصور والرتب (تقدر تعدلها لاحقاً من الداشبورد).
2. `/apply_panel` في الروم اللي تبي يقدمون منه.
3. `/notice_panel` لنشر لوحة التجمعات.

## الملفات

كل شيء في ملف واحد: **`bot.py`** (البوت + الداشبورد + توليد الصور). الباقي ملفات تشغيل فقط (`requirements.txt` و`.env.example`).

## الصور

صور المشروع والأيقونات وأمثلة البطاقات في مجلد `images/` ويمكن إعادة توليدها بـ `python bot.py assets` (غيّر الاسم بالمتغير `BOT_NAME` والخط بـ `ASSET_FONT`).

| الملف | الاستخدام |
|---|---|
| `avatar.png` | صورة البوت في ديسكورد |
| `banner.png` | ترويسة الـ README |
| `social-preview.png` | GitHub → Settings → Social preview |
| `logo.png` / `panel-example.png` | اللوقو ومثال لوحة المنتدى |
